# Read Us! 리더스

읽은 책을 한 권씩 쌓아 우주까지 올라가는 학급 독서기록장입니다.
아이들이 읽은 책의 제목·지은이·출판사·감상을 적어 보내면, 선생님이 승인할 때마다 우리 반 책탑에 한 권(30cm)씩 쌓입니다.

- 화면 주소: https://musicalpe.github.io/readus/
- 지금 판: 화면 0.1.2 · 껍데기 1판

## 할 수 있는 것

- **책 기록**: 학생이 이름을 고르고 읽은 책과 감상을 적어 보냅니다.
- **선생님 승인**: 승인하면 책탑에 쌓이고, "다시 써 오기"로 돌려보낼 수도 있습니다.
- **우리 반 책탑 현황판**: 쌓인 높이를 교실 천장, 학교 건물, 아파트 같은 비교 대상과 함께 보여 줍니다.
- **감상 기준 안내**: 선생님이 정한 기준(문장 수·글자 수)보다 짧으면 보내기 전에 한 번 더 생각해 보게 합니다. 그대로 보내는 것도 막지 않습니다.
- **학급 도서**: 우리 반이 함께 읽을 책과 기한을 정해 권합니다. 기한이 지나도 기록할 수 있습니다.

## 설치 (선생님)

학생 명단과 기록은 선생님의 구글 스프레드시트에만 저장됩니다.

### 방법 A. 견본 시트 사본 만들기 (쉬움)

1. [견본 시트 사본 만들기](https://docs.google.com/spreadsheets/d/1i-lr4aewTmhj4eJ-hfXgjxaPzflmMyLMn-aqUepZjls/copy)를 눌러 내 드라이브에 사본을 만듭니다. 껍데기가 이미 들어 있습니다.
2. 사본의 이름을 우리 반 이름으로 바꿉니다. (예: 햇살초 5학년 1반) 이 이름이 화면에 보입니다.
3. 메뉴 **확장 프로그램 → Apps Script** 를 열고, 아래 "배포하기"로 갑니다.

### 방법 B. 직접 붙여 넣기

1. 구글 드라이브에서 새 스프레드시트를 만들고 이름을 정합니다. (예: 햇살초 5학년 1반) 이 이름이 화면에 보입니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 들어 있는 내용을 모두 지우고, 이 저장소의 `Shell.gs` 내용을 통째로 붙여 넣은 뒤 저장합니다.

### 배포하기 (A·B 공통)

1. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱** 을 고릅니다.
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
2. 배포하면 나오는 **웹 앱 주소**(…/exec)를 엽니다. "프로그램 열기" 단추를 누르면 우리 반 화면이 열립니다.
3. 열린 주소를 즐겨찾기해 두고, 학생들에게도 같은 주소를 알려 줍니다. (선생님 화면 → 설정 → 학생에게 알려 줄 주소)
4. **선생님** 단추로 들어가(처음 비밀번호 1234) 비밀번호를 바꾸고 학생을 등록합니다.

껍데기를 고쳐서 다시 배포할 때는 꼭 **배포 관리 → 수정 → 새 버전**으로 해야 주소가 바뀌지 않습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 전체 (현황판·학생·선생님) |
| `Shell.gs` | 학교 시트에 붙이는 껍데기. 시트에 읽고 쓰는 일만 합니다. |
| `Relay.gs` | 책 검색 중계기. 운영자만 설치합니다. 학교에서는 설치하지 않습니다. |
| `relay.json` | 중계기 주소. 비어 있으면 책 찾기 칸이 보이지 않고 직접 적습니다. |
| `changelog.json` | 판올림 내역 (맨 위가 최신) |
| `dev/`, `tests/` | 시험 도구 |

## 올리기 전 시험

고친 뒤에는 올리기 전에 아래를 돌립니다. 하나라도 걸리면 올리지 않고 먼저 고칩니다.

- **단순 수정**(글귀·색·여백·그림): 코드 검사만
  ```
  node tests/check.js
  ```
- **기능 수정**(새 기능·화면 배치·저장 방식): 코드 검사 + 전체 시험. 애매하면 전체 시험.
  ```
  cd dev && npm install      # 처음 한 번
  cd .. && node tests/check.js && python3 tests/full.py
  ```
  전체 시험은 가짜 학교 시트(`dev/gas-emu.js`)로 화면을 실제로 띄워 로그인·학생 등록·기록·승인·현황판까지 밟아 봅니다.

화면을 직접 보려면 `cd dev && SEED=1 node devserver.js` 를 띄우고
`http://localhost:8891/readus/?s=http%3A%2F%2Flocalhost%3A8891%2Fexec` 를 엽니다.
